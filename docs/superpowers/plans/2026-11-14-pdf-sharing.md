# PDF sharing implementation plan

Goal: receive a shared PDF in the installed personal web app and open Imports & review without reading or posting until the user selects the account/password and presses Read PDF.

Scope replaces Gmail implementation for this task. Android browsers with Web Share Target support can expose the installed app in Share. Keep the manifest declaration standards-based so future Safari support can use it; current iPhone users retain Save to Files / Choose statement. No deployment, beta edits, dependencies, Gmail access or ledger schema changes.

- [x] Register a PDF-only multipart POST share target at /share-statement in public/manifest.json. Intercept this exact route in public/sw.js before ordinary caching, never send shared bytes to Netlify. Add public/share-target.js for bounded temporary IndexedDB staging, ten-minute expiry, validated single PDF, one-use retrieval via service-worker message. Never cache intake URLs. Include worker helper content in the production worker version hash.
- [x] Add src/data/sharedPdf.ts: capture launch parameters, request the staged file with MessageChannel, deduplicate StrictMode reads in memory, friendly expired/invalid/storage errors. Let App.tsx select Transactions and TransactionsScreen.tsx select Imports for this launch, including after the account gate. Remove intake query parameters after capturing them.
- [x] In StatementWorkspace.tsx show the shared filename, existing account/password fields, explicit Read PDF, and cancellation. Reuse read(file), existing source checks and review. Keep file only in memory after retrieval; allow wrong-password retry, clear on cancel/commit, do not discard a preview accidentally on a late retrieval.
- [x] Add synthetic service-worker tests for validation, expiry, one-use retrieval, simultaneous shares, storage failures, cache bypass and production helper changes. Add mobile/desktop production browser tests for multipart POST, direct import routing, no automatic read/post, password retry, source totals, duplicate import, reload/backup preservation, cancellation, invalid/expired shares and no PDF network request. Run typecheck/build and affected existing PDF/import checks.
- [x] Document installation/update requirements and current Safari limitation. Review final diff and keep unrelated user files untouched. No live share sheet or physical iPhone/Android verification can be claimed from desktop automation.
