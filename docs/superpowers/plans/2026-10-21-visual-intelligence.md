# Visual financial intelligence

**Goal:** Replace report-like coach paragraphs with an interactive visual analysis workspace, prioritising petty expenses and cards.
**Design:** Five focused views (Drivers, Petty, Cards, Income, Review). Slate/system typography from the app; teal overall spending, amber petty payments, violet cards, rose increases and green decreases. One main analytical graphic per view, concise numeric callouts, evidence on selection, prose only in a detail sheet. No decorative animation or new chart dependency.
**Architecture:** Reuse the tested dashboard/coach/insight calculations. Add pure waterfall/treemap/bubble/cohort geometry helpers; SVG and native controls remain keyboard accessible. Preserve income, habit approval, scenario and source/ledger evidence flows. Existing supporting charts move behind disclosure. No schema migration or production deployment.

**Truthfulness:** The local engine is deterministic and explainable. A model connection is a separate pending user choice; no financial summaries leave the device without authorization. Do not label local calculations as generative AI. Missing income/source controls stay unknown. Petty and card overlap counts once. Source debit/credit movements are separate from posted spending. Category and frequency bridges are alternative explanations, not additive causes.
